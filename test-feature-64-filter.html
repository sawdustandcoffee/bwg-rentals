Filter Parameters

The bwg_booking_button_text filter receives two parameters:

  1. $text (string): The button text (already escaped with esc_html)
  2. $property (array): The complete property data object

Example: Property-specific text

add_filter('bwg_booking_button_text', function($text, $property) { if (isset($property['name'])) { return 'Book ' . $property['name']; } return $text; }, 10, 2);
