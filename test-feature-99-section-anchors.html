🧪 Feature #99: [bwg_property] Section Anchors

Feature: Property pages include section anchor navigation

Category: Single Property Page

Status: Testing

Test Instructions

1. Create a Test Page in WordPress

Go to Pages → Add New and create a page called "Feature 99 - Section Anchors Test"

2. Add the Shortcode

Add this shortcode to the page content:

[bwg_property id="123" show_anchors="true"]

Note: Replace "123" with an actual property ID from your API

3. Verify Section IDs

  1. View the page on the frontend
  2. Open browser DevTools (F12)
  3. Inspect the page HTML
  4. Verify these section IDs exist:
    • id="bwg-section-gallery"
    • id="bwg-section-description"
    • id="bwg-section-amenities"
    • id="bwg-section-availability"
    • id="bwg-section-rates"
    • id="bwg-section-location"
    • id="bwg-section-policies"

4. Verify Anchor Navigation Menu

  1. Look for a navigation menu in the sidebar titled "On this page"
  2. Verify it lists all visible sections
  3. Verify the links have format #bwg-section-[name]

5. Test Anchor Links

  1. Click on each anchor link in the "On this page" menu
  2. Verify the page scrolls smoothly to that section
  3. Verify the URL updates with the hash (e.g., #bwg-section-amenities)
  4. Try refreshing with a hash in URL - page should scroll to that section

6. Test Direct Hash Navigation

  1. Manually add hash to URL: /your-page/#bwg-section-rates
  2. Press Enter
  3. Verify page loads scrolled to the Rates section

7. Test show_anchors="false"

Update shortcode to:

[bwg_property id="123" show_anchors="false"]
  1. Save and refresh the page
  2. Verify the "On this page" navigation menu is NOT visible
  3. Verify section IDs still exist (for direct hash linking)

✅ Expected Results

  • All sections have unique ID attributes
  • "On this page" navigation menu appears in sidebar (when show_anchors="true")
  • Navigation menu only shows sections that are visible
  • Clicking anchor links scrolls smoothly to sections
  • Browser URL updates with hash when clicking links
  • Direct hash URLs work (page loads scrolled to section)
  • Navigation menu hidden when show_anchors="false"
  • Smooth scroll behavior is applied
  • Links are keyboard accessible (Tab navigation works)
  • Hover states work correctly

8. Accessibility Testing

  1. Use keyboard Tab key to navigate to anchor links
  2. Verify focus styles are visible
  3. Press Enter on focused link - should scroll to section
  4. Verify nav element has aria-label="Jump to section"

9. Responsive Testing

  1. Resize browser to mobile width (<768px)
  2. Verify anchor navigation adapts or hides appropriately
  3. Test on tablet width (768px-991px)
  4. Verify anchor navigation shows as horizontal tabs

Quick Test URL

If you have a page with the shortcode already created, test these URLs:

  • http://localhost:8088/your-test-page/ - Base page
  • http://localhost:8088/your-test-page/#bwg-section-amenities - Jump to amenities
  • http://localhost:8088/your-test-page/#bwg-section-rates - Jump to rates
  • http://localhost:8088/your-test-page/#bwg-section-location - Jump to location
