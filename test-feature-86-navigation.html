Feature #86: [bwg_property_slider] navigation attribute

Feature Description: Slider navigation can be customized (arrows, dots, both, none)

Test 1: Default (navigation="both")

Shortcode: [bwg_property_slider]

✓ Expected: Shows both arrow buttons AND dot indicators (default)

[bwg_property_slider]

Test 2: Arrows Only (navigation="arrows")

Shortcode: [bwg_property_slider navigation="arrows"]

✓ Expected: Shows only arrow buttons, NO dot indicators

[bwg_property_slider navigation="arrows"]

Test 3: Dots Only (navigation="dots")

Shortcode: [bwg_property_slider navigation="dots"]

✓ Expected: Shows only dot indicators, NO arrow buttons

[bwg_property_slider navigation="dots"]

Test 4: No Navigation (navigation="none")

Shortcode: [bwg_property_slider navigation="none"]

✓ Expected: Shows NO arrows and NO dots (autoplay only, or swipe on mobile)

[bwg_property_slider navigation="none"]

Test 5: Both Explicitly (navigation="both")

Shortcode: [bwg_property_slider navigation="both"]

✓ Expected: Shows both arrow buttons AND dot indicators

[bwg_property_slider navigation="both"]

Test 6: Invalid Value Falls Back to Default

Shortcode: [bwg_property_slider navigation="invalid"]

✓ Expected: Falls back to "both" (shows arrows and dots)

[bwg_property_slider navigation="invalid"]

Test 7: Navigation with Autoplay

Shortcode: [bwg_property_slider navigation="none" autoplay="true" speed="3000"]

✓ Expected: Auto-advancing slider with NO navigation controls

[bwg_property_slider navigation="none" autoplay="true" speed="3000"]
