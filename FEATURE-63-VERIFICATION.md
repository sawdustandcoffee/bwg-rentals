### 3. Output Generation (Lines 614-624)

**Code:**
```php
$allowed_tags = array( 'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'p', 'span', 'div' );
```

### 4. Filter Use Cases

**Example 1: Wrap title in custom container**
```php
// In theme's functions.php or mu-plugin
add_filter('bwg_property_title_output', function($output, $property) {
    return '<div class="custom-title-wrapper">' . $output . '</div>';
}, 10, 2);
```

**Result:**
```html
<div class="custom-title-wrapper">
    <h1 class="bwg-property-title">Oceanview Cottage</h1>
</div>
```

---

**Example 2: Add property ID as data attribute**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    $property_id = isset($property['id']) ? $property['id'] : '';
    return str_replace(
        'class="bwg-property-title',
        'data-property-id="' . esc_attr($property_id) . '" class="bwg-property-title',
        $output
    );
}, 10, 2);
```

**Result:**
```html
<h1 data-property-id="123" class="bwg-property-title">Oceanview Cottage</h1>
```

---

**Example 3: Add property type badge**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    if (isset($property['type'])) {
        $badge = '<span class="property-type-badge">' . esc_html($property['type']) . '</span>';
        $output = str_replace('</h1>', ' ' . $badge . '</h1>', $output);
    }
    return $output;
}, 10, 2);
```

**Result:**
```html
<h1 class="bwg-property-title">Oceanview Cottage <span class="property-type-badge">Cottage</span></h1>
```

---

**Example 4: Conditional formatting based on property status**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    $is_featured = isset($property['featured']) && $property['featured'];

    if ($is_featured) {
        $output = str_replace(
            'class="bwg-property-title',
            'class="bwg-property-title featured-property',
            $output
        );
        $output = str_replace('</h1>', ' ⭐</h1>', $output);
    }

    return $output;
}, 10, 2);
```

**Result for featured property:**
```html
<h1 class="bwg-property-title featured-property">Oceanview Cottage ⭐</h1>
```

---

### Edge Case 3: Filter returns null/false
**Code:**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    return null; // Accidentally returns null
}, 10, 2);
```

**Result:** Shortcode returns `null`, WordPress renders empty string
✅ **Gracefully handled** (no PHP error, just no output)

**Better practice:** Always return a string
```php
add_filter('bwg_property_title_output', function($output, $property) {
    // Hide title for certain properties
    if (isset($property['hide_title']) && $property['hide_title']) {
        return ''; // Return empty string, not null
    }
    return $output;
}, 10, 2);
```

---

### Edge Case 4: Filter doesn't return anything
**Code:**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    // Forgot to return!
    $output = '<div>' . $output . '</div>';
}, 10, 2);
```

**Result:** Returns `null`, same as Edge Case 3
✅ **Gracefully handled** but likely developer error

---

### Edge Case 5: Filter modifies $property array (not $output)
**Code:**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    $property['name'] = 'Modified Name'; // Modify $property, not $output
    return $output; // Return original output

```

**Result:** No change to output (correct behavior)
✅ **Works as expected** - modifying `$property` doesn't affect already-generated `$output`

**Note:** `$property` is passed by value (array), so modifications don't persist beyond the filter

## Performance Considerations

### Filter Execution Cost

**Scenario 1: No filters added**
- Cost: ~1 microsecond (WordPress checks for hooks)
- Impact: Negligible

**Scenario 2: One simple filter**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    return '<div>' . $output . '</div>';
}, 10, 2);
```
- Cost: String concatenation + function call
- Impact: < 10 microseconds, negligible

**Scenario 3: Complex filter with database query**
```php
add_filter('bwg_property_title_output', function($output, $property) {
    $rating = get_post_meta($property['id'], 'rating', true); // Database query
    return $output . ' (' . $rating . ' stars)';
}, 10, 2);
```
- Cost: Database query + string operations
- Impact: ~1-5 milliseconds per shortcode call
- Recommendation: Cache results or check if `$property` already contains rating

### Optimization Best Practices

**Good:** Modify output with string operations
```php
add_filter('bwg_property_title_output', function($output, $property) {
    return str_replace('class="', 'class="custom ', $output);
}, 10, 2);
```

**Bad:** Make external API calls in filter
```php
// DON'T DO THIS - blocks page rendering
add_filter('bwg_property_title_output', function($output, $property) {
    $weather = file_get_contents('https://api.weather.com/...');
    return $output . ' - ' . $weather;
}, 10, 2);
```

**Recommendation for developers:**
- ✅ Use data from `$property` array (already loaded)
- ✅ Perform lightweight string operations
- ✅ Cache expensive computations
- ❌ Avoid database queries in filter
- ❌ Avoid external API calls in filter
