Implementation Details

Files Modified:

  • includes/class-bwg-shortcodes.php
    • Added show_related and related_limit attributes to property_full() method
    • Added get_related_properties() method with similarity scoring algorithm
    • Fetches related properties before rendering template
  • templates/property-full.php
    • Added related properties section after main content
    • Displays up to 4 property cards with image, title, specs, and link
    • Conditional rendering based on show_related attribute
  • assets/css/bwg-rentals-public.css
    • Added .bwg-property-full__related styles
    • Added .bwg-related-properties grid layout
    • Added .bwg-related-property-card component styles
    • Responsive breakpoints for mobile/tablet

Similarity Algorithm:

  • Bedroom Matching (0-100 points):
    • Exact match: +100 points
    • ±1 bedroom: +50 points
    • ±2 bedrooms: +25 points
  • Location Matching (0-50 points):
    • Same city: +50 points
    • Same state: +25 points
  • Properties sorted by total score (highest first)
  • Top 4 properties returned (configurable via related_limit attribute)

Usage Examples:

<!-- Default: show related properties -->
[bwg_property id="123"]

<!-- Explicitly show related properties -->
[bwg_property id="123" show_related="true"]

<!-- Hide related properties -->
[bwg_property id="123" show_related="false"]

<!-- Show only 3 related properties -->
[bwg_property id="123" related_limit="3"]
