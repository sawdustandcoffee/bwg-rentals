Feature #35: [bwg_property_availability] basic rendering

Feature Definition

Category: Single Property Shortcodes

Description: The availability shortcode displays availability calendar

Dependencies: Feature #4 (API credentials can be saved) - PASSING

Step 1: Add [bwg_property_availability id="X"]

Test URL: http://localhost:8000/?p=1

  • Navigate to a page with the shortcode
  • Page loads without errors
  • Shortcode is rendered (not shown as raw text)

Step 2: Verify calendar displays

  • Calendar container is visible
  • Month title(s) are displayed
  • Days of week headers are shown
  • Calendar grid shows dates
  • Available/unavailable dates are color-coded
  • Legend shows available/unavailable indicators
  • Navigation buttons (Previous/Next) are present
  • No JavaScript errors in console
  • CSS styling is applied correctly

  1. Open WordPress admin: http://localhost:8000/wp-admin
  2. Create a new page or edit existing page
  3. Add shortcode: [bwg_property_availability id="1"]
  4. Publish the page
  5. View the page on the frontend
  6. Take screenshots of calendar display
  7. Test navigation buttons
  8. Verify different months load
