Feature #82: Property Search Compact Mode - Test

Test 1: Compact Mode Enabled

Shortcode: [bwg_property_search compact="true"]

Expected: Only shows Check-In, Check-Out, and Guests fields. "More Filters" button shows Bedrooms, Amenities, and Location when clicked.

Test 2: Normal Mode (No Compact)

Shortcode: [bwg_property_search]

Expected: Shows all filter fields (dates, guests, bedrooms, amenities, location) without "More Filters" button.

Test 3: Compact Mode with Limited Filters

Shortcode: [bwg_property_search compact="true" show_amenities="false"]

Expected: Compact mode, but amenities filter hidden even in expanded state.

  1. Navigate to http://localhost:8088/feature-82-compact-mode-test/

  3. Click "More Filters" button
  4. Verify additional fields appear (Bedrooms, Amenities, Location)
  5. Click "More Filters" again to collapse
  6. Verify fields hide again
  7. In Test 2, verify all fields visible without toggle button
  8. Test form submission works in both modes
