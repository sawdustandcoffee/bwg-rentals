### Compact vs Standard Comparison

| Element | Standard | Compact | Change |
|---------|----------|---------|--------|
| Max Width | 1200px | 900px | -25% |
| Title Size | 2.5rem | 2rem | -20% |
| Heading Size | 1.5rem | 1.25rem | -17% |
| Section Spacing | 24px (lg) | 16px (md) | -33% |
| Specs Layout | Vertical (column) | Horizontal (row) | Layout |
| Specs Icon | 2rem | 1.5rem | -25% |
| Amenities Columns | 2 | 1 | -50% |
| Button Font | 1.125rem | 1rem | -11% |
| Body Text | 1rem | 0.9375rem | -6% |

### Key Compact Layout Features

1. **Space Efficiency** - 25% narrower max-width (900px vs 1200px)
2. **Tighter Spacing** - Uses md (16px) instead of lg (24px) throughout
3. **Smaller Typography** - All fonts reduced 6-20% while maintaining readability
4. **Horizontal Specs** - Icons, values, labels displayed inline (saves vertical space)
5. **Single Column Lists** - Amenities in 1 column (better for narrow spaces)
6. **Inline Policies** - Label and value side-by-side instead of stacked
7. **Compact Rates** - Smaller padding and fonts in rate displays
8. **Smaller Button** - Booking button proportionally reduced

### Usage Examples

```
<!-- Standard layout (default) -->
[bwg_property id="1"]

<!-- Compact layout (Feature #96) -->
[bwg_property id="1" layout="compact"]

<!-- Compact with custom sections -->
[bwg_property id="1" layout="compact" show_availability="false" show_policies="false"]
```
