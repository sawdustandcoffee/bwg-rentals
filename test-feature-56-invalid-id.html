Feature #56: Invalid Property ID Shows Error

Feature Definition

Feature #56: Invalid property ID shows error

Description: Shortcodes show error for non-existent property IDs

Dependencies: Feature #55

Steps:

  1. Use shortcode with invalid id
  2. Verify appropriate error message

Test 1: Invalid ID in [bwg_property_title]

[bwg_property_title id="99999"]
Test URL:
http://localhost:8088/feature-56-invalid-id-test/
Expected Behavior:
  • ✅ Error message displayed (not blank output)
  • ✅ Error message is user-friendly (e.g., "Property not found" or "Invalid property ID")
  • ✅ Error message is styled appropriately (error class)
  • ✅ No PHP warnings or errors in output

Test 2: Invalid ID in [bwg_property_gallery]

[bwg_property_gallery id="88888"]
Expected Behavior:
  • ✅ Error message displayed
  • ✅ Message indicates property not found
  • ✅ No broken image placeholders

Test 3: Invalid ID in [bwg_property_specs]

[bwg_property_specs id="77777"]
Expected Behavior:
  • ✅ Error message displayed
  • ✅ No attempt to display null/undefined data

Test 4: Missing ID Parameter

[bwg_property_title]
Expected Behavior:
  • ✅ Error message: "Property ID is required" or similar
  • ✅ Graceful handling of missing parameter

Test 5: ID = 0

[bwg_property_availability id="0"]
Expected Behavior:
  • ✅ Error message displayed
  • ✅ ID of 0 is treated as invalid

Verification Checklist

To mark Feature #56 as PASSING, verify ALL of the following:

  • ❌ Each shortcode with invalid ID shows an error message
  • ❌ Error messages are user-friendly and descriptive
  • ❌ No PHP warnings/errors in the HTML output
  • ❌ No blank/empty output (always shows either content or error)
  • ❌ Console shows no JavaScript errors
  • ❌ Error styling is consistent across all shortcodes

How to Test

  1. Create a WordPress page with the URL slug: feature-56-invalid-id-test
  2. Add each of the shortcodes above to the page content
  3. Publish the page
  4. Visit the test URL and verify error messages appear
  5. Check browser console for errors
  6. Take screenshots for documentation
