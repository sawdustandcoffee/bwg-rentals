### Similarity Matching Algorithm

The `get_related_properties()` method uses a weighted scoring system:

**Bedroom Similarity (0-100 points):**
- Exact match (same bedrooms): +100 points
- Close match (±1 bedroom): +50 points
- Somewhat similar (±2 bedrooms): +25 points

**Location Matching (0-50 points):**
- Same city: +50 points
- Same state: +25 points

**Sorting & Filtering:**
- Properties scored and sorted by total similarity (highest first)
- Only properties with score > 0 included (some similarity required)
- Top N properties returned (default 4, configurable via related_limit)
- Current property excluded from results

### Usage Examples

```
<!-- Default: show 4 related properties -->
[bwg_property id="123"]

<!-- Explicitly enable related properties -->
[bwg_property id="123" show_related="true"]

<!-- Hide related properties section -->
[bwg_property id="123" show_related="false"]

<!-- Show only 3 related properties -->
[bwg_property id="123" related_limit="3"]

<!-- Show 6 related properties -->
[bwg_property id="123" related_limit="6"]

<!-- Combine with other attributes -->
[bwg_property id="123" layout="compact" show_related="true" related_limit="3"]
```

### Edge Cases Handled

1. **No similar properties found:**
   - Returns empty array
   - Template conditional prevents section from showing
   - No error messages displayed

2. **API error:**
   - get_properties() returns WP_Error
   - Method returns empty array
   - Section gracefully hidden

3. **Current property excluded:**
   - Checks property ID and skips current property
   - Prevents same property from appearing in related list

4. **Properties with no location data:**
   - Still matched by bedroom similarity
   - Location score defaults to 0 (not penalized)

5. **Properties with 0 similarity score:**
   - Excluded from results entirely
   - Only shows truly related properties
