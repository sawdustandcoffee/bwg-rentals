Feature #17: [bwg_property_card] show_specs attribute

Test Objective: Verify that the show_specs attribute controls visibility of property specifications.

Test 1: show_specs="true"

Explicit show_specs="true"
[bwg_property_card id="1" show_specs="true"]
Expected: Specs section visible (beds, baths, guests)

Test 2: Default behavior

No show_specs attribute (should default to true)
[bwg_property_card id="1"]
Expected: Specs section visible (default)

Test 3: show_specs="false"

Explicit show_specs="false"
[bwg_property_card id="1" show_specs="false"]
Expected: NO specs section (only image and name)

Test 4: Combination test

show_image="true" show_specs="false"
[bwg_property_card id="1" show_image="true" show_specs="false"]
Expected: Image shown, specs hidden
