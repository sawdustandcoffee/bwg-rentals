Feature Definition

Feature #87: [bwg_property_slider] loop attribute

Description: Slider can loop infinitely or stop at ends

Steps:

  1. Add loop attribute (true/false)
  2. Infinite loop seamlessly wraps
  3. Non-loop disables prev/next at ends

Test 1: Loop Mode Enabled (loop="true")

[bwg_property_slider limit="5" loop="true"]
Expected Behavior:
  • ✅ Previous and Next buttons are always enabled
  • ✅ Clicking Next on the last slide wraps to the first slide
  • ✅ Clicking Previous on the first slide wraps to the last slide
  • ✅ Infinite navigation in both directions

Manual Test Steps:

  1. Navigate to the last slide (slide 5/5)
  2. Click "Next" button - Should seamlessly wrap to slide 1/5
  3. Click "Previous" button - Should seamlessly wrap back to slide 5/5
  4. Use keyboard arrows - Left/Right should loop infinitely
  5. Verify buttons are never disabled

Test 2: Loop Mode Disabled (loop="false")

[bwg_property_slider limit="5" loop="false"]
Expected Behavior:
  • ✅ Previous button is disabled on the first slide
  • ✅ Next button is disabled on the last slide
  • ✅ Clicking disabled buttons has no effect
  • ✅ Navigation stops at both ends

Manual Test Steps:

  1. Check initial state - Previous button should be disabled
  2. Navigate to the last slide (slide 5/5)
  3. Next button should be disabled
  4. Try clicking disabled buttons - No movement
  5. Use keyboard arrows - Should stop at ends

Test 3: Default Behavior (no loop attribute)

[bwg_property_slider limit="5"]
Expected Behavior:
  • ✅ Default is loop="true" (infinite looping)
  • ✅ Buttons always enabled
  • ✅ Seamless wrapping in both directions

Manual Test Steps:

  1. Verify behavior matches Test 1 (loop enabled)
  2. Default attribute value should be "true"

Implementation Summary

Files Modified:

  • includes/class-bwg-shortcodes.php - Added loop attribute (default: 'true')
  • templates/property-slider.php - Added data-loop attribute
  • assets/js/bwg-rentals-public.js - Implemented loop/non-loop logic

JavaScript Changes:

  • Previous button: Wraps to end when loop=true and at beginning
  • Next button: Wraps to start when loop=true and at end
  • updateSlider(): Disables buttons at ends when loop=false
  • Keyboard navigation: Supports looping with arrow keys
  • Touch/swipe: Supports looping on mobile devices
