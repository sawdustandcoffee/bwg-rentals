#### Similarity Algorithm:

**Bedroom Matching (0-100 points):**
- Exact match: +100 points
- ±1 bedroom: +50 points
- ±2 bedrooms: +25 points

**Location Matching (0-50 points):**
- Same city: +50 points
- Same state: +25 points

**Filtering and Sorting:**
- Properties scored by total similarity (bedroom + location)
- Only properties with score > 0 included
- Sorted by score (highest first)
- Top N properties returned (configurable via related_limit)
- Current property excluded from results
