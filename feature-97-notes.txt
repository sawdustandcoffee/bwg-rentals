## Feature #97: Add show_filters attribute to [bwg_properties] shortcode

**Status: IMPLEMENTED AND VERIFIED**

### Implementation Summary:
Added a new `show_filters` attribute to the `[bwg_properties]` shortcode that controls the visibility of filter controls (beds, baths, sleeps, sort by).

**New Attribute:**
- `show_filters` - Show/hide filter controls (default: 'true')
- Accepts: 'true', 'false', '1', '0', true, false
- Default: 'true' (backward compatible - filters shown by default)

**Files Modified:**
1. includes/class-bwg-shortcodes.php - Added 'show_filters' attribute
2. templates/properties-grid.php - Conditional filter rendering
3. templates/properties-list.php - Conditional filter rendering
4. templates/properties-masonry.php - Conditional filter rendering
