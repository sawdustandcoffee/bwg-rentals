================================================================================
XSS VULNERABILITY HISTORY
================================================================================

ISSUE: Inline onclick handler in property-search.php
Location: templates/property-search.php line 103
Discovered: During Feature #70 audit
Actually Fixed: Feature #79 (commit ed711cd)

VULNERABLE CODE (Feature #79 removed this):
  <button onclick="window.location.href='<?php echo esc_url(...); ?>';">

SECURE CODE (Feature #79 implemented this):
  <button data-clear-url="<?php echo esc_url(...); ?>">

JavaScript Handler (Feature #79 added this):
  var clearUrl = $(this).data('clear-url');
  window.location.href = clearUrl;

WHY THIS MATTERS:
- esc_url() in JavaScript context is insufficient
- Attacker could inject: javascript:alert('XSS')
- Data attributes + external handlers prevent injection
- Separation of HTML and JavaScript improves security
