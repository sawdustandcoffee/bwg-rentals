#### Feature Definition:
- ID: 52

- Description: Shortcodes with non-existent property IDs display helpful message
- Category: functional
- Dependencies: Feature #27 ([bwg_property_title] renders property name) PASSED
- Steps:
  1. Add shortcode with invalid ID: [bwg_property_title id='99999999']
  2. View page on frontend
  3. Verify user-friendly error message displays
  4. Verify no PHP errors occur

#### Bug Found and Implemented Fix:

**Original Bug:**
When a shortcode was used with an invalid property ID (e.g., [bwg_property_title id="99999"]), the mock API was returning data from the first property instead of an error. This meant users would see misleading data instead of an error message.

**Root Cause:**
In includes/class-bwg-api.php, the get_mock_property() method was returning the first property as a fallback when an invalid ID was requested.

**Implementation:**
1. Modified get_mock_property() to return null when property ID not found
2. Updated maybe_mock_api_response() to return 404 status when property is null
3. Added user-friendly error messages for common HTTP status codes:
   - 404: Property not found. Please check the property ID.
   - 401/403: API authentication failed. Please check your API credentials.
   - 500/502/503: The property service is temporarily unavailable.
