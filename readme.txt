Display vacation rental properties from Direct Software on your WordPress site with flexible shortcodes.

== Description ==

BWG Rentals integrates with the Direct Software vacation rental API to display properties on WordPress websites. The plugin provides flexible shortcodes for page builder compatibility, allowing admins to create custom property archive pages and detailed single property pages.

**Features:**

* Display property grids or lists
* Individual property shortcodes for complete layout control
* Availability calendar integration
* Responsive design
* Caching for optimal performance
* Automatic updates from GitHub releases

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/bwg-rentals/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings > BWG Rentals to configure API credentials
4. Use shortcodes on your pages

== Frequently Asked Questions ==

= Where do I get API credentials? =

You need a Direct Software account. Contact Direct Software to obtain your API Key and Organization ID.

= How do I display properties? =

Use the `[bwg_properties]` shortcode on any page to display a grid of all properties.

= Can I customize the appearance? =

Yes! The plugin uses CSS custom properties and BEM naming. You can also override templates in your theme.
