Feature #57: API Connection Failure Shows Error

Feature Category: Error Handling
Description: Graceful error handling when API is unreachable
Dependencies: Feature #55 (Missing property ID shows error) - PASSING
Feature Steps:
  1. Disconnect API or use invalid credentials
  2. Use shortcode
  3. Verify friendly error message

Test Plan

This feature tests that when the API is unreachable or credentials are invalid, the plugin displays user-friendly error messages instead of crashing or showing technical errors.

Error Scenarios to Test:

  1. Invalid API Credentials (401/403) - "API authentication failed"
  2. Network Timeout - "Unable to connect to the property service. The server is taking too long to respond."
  3. Network Connection Error - "Unable to connect to the property service. Please check your internet connection."
  4. Server Error (500/502/503) - "The property service is temporarily unavailable"
  5. Property Not Found (404) - "Property not found. Please check the property ID."
  6. No Credentials - "API credentials not configured."

Test 1: Invalid API Credentials (Will simulate via MOCK)

Steps:
  1. Create a test page with shortcode [bwg_properties]
  2. Temporarily set API key to empty or invalid value
  3. View the page
  4. Verify error message displays: "API credentials not configured." or "API authentication failed."

Expected: User-friendly error message, NOT a PHP error or blank page

Test 2: Network Timeout (Simulate with MOCK_TIMEOUT_)

Steps:
  1. Set API key to "MOCK_TIMEOUT_TEST" to simulate timeout
  2. Use shortcode [bwg_property id="1"]
  3. Verify timeout error message displays

Expected: "Unable to connect to the property service. The server is taking too long to respond. Please try again later."

Test 3: Property Not Found (404)

Steps:
  1. Use valid API credentials
  2. Use shortcode with non-existent property ID: [bwg_property id="99999"]
  3. Verify 404 error message displays

Expected: "Property not found. Please check the property ID."

Test 4: Single Property Shortcodes with API Errors

Test that ALL property shortcodes handle errors gracefully:

  • [bwg_property_title id="1"]
  • [bwg_property_gallery id="1"]
  • [bwg_property_specs id="1"]
  • [bwg_property_description id="1"]
  • [bwg_property_amenities id="1"]
  • [bwg_property_availability id="1"]
  • [bwg_property_rates id="1"]
  • [bwg_property_booking_button id="1"]
  • [bwg_property_location id="1"]
  • [bwg_property_policies id="1"]
